### 发布前自检（pyflakes 全包扫描）

抓到三个**被 `except: pass` 吞掉的未定义名**，都是"功能安静地不存在"型：

| 位置 | 根因 | 后果 |
|---|---|---|
| `desktop.py` 发送成功后 | `_M.observe_habit` 的 `_M` 从未 import | 习惯观察从未执行，`habits` 恒空 |
| `desktop.py` 发送失败分支 | `f"{r.detail}"` 引用不存在的 `r` | 首条失败抛 NameError，冒到 watcher 线程 |
| `_maybe_narrative` 外层 except | 模型异常时不 `mark_done` | 每 5 秒重试，直到 30 分钟窗口结束 |

**结论**：`pyflakes` 未定义名 0 条、`compileall` 通过、模块 import 50/50。
这三个 bug 提醒一件事：**`except: pass` 是这个项目最大的藏 bug 的地方** ——
以后新增的 except 至少要记一行 `self._log(..., "")`，不要静默。

**刻意的取舍（记着，不要当成 bug 再查一遍）**：
- 原文检索按会话隔离后，**群里说的话在私聊里检索不到**（原文层）。
  事实层（`facts`）仍然跨窗口共享。这是隐私优先的取舍。
- `chunk_hits` 命中加权仍然失效（在 `mode=ro` 连接上写，异常被吞）——
  它只影响排序微调，不影响能不能检索到。要修的话是独立一件事。
- `mood-config` 里 `injectMode`/`sigMood`/`autoJudge` 等仍无消费者。

**刻意没做**：一条到本地的工具调用（0.11 的事）、流式、观测面板 ——
这一版的目的是让已有的器官真的通电，不是加新器官。
