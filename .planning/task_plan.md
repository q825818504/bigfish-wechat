## 本轮教训（值得单独记）

这几条都是**实测才暴露**的，单靠单元测试活不下来：

1. **回环判定不能看「文字像不像」** —— 对方复述她的话是聊天，不是回环。
   判据必须是 `msg.is_self` + 内容匹配两条同时成立。

2. **「读路径铺好了」不等于「功能完整」** —— 记忆和心情的读一直很全，
   写路径一行没有。测试全绿、界面正常，就是没人写。这类「缺一块」的问题
   只能靠真实调用来发现。

3. **`.lnk` 的 IconLocation 指向独立 ico 会失败** —— Shell 用 32px 尺寸
   按索引取第 0 帧，对不上就退通用图标。不指定反而对（继承 exe 内嵌）。

4. **`os.access(W_OK)` 在 Windows 上不可信** —— 只查 ACL，不查上层策略。
   只有真写一个探针文件才算数。

5. **打包脚本可能从没产出过某个文件** —— `setup.zip` 一直是手工打的，
   每次打包都不更新它。发布出去的包里躺着旧 exe。
