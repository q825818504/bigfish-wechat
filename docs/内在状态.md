# 内在状态：预算 / 余韵 / 被无视

> v0.10.0 起生效。这一层回答的是：**她的心情和精力，到底改变了什么。**

---

## 一、三条回路

```
被无视（8 小时没回）
    → 心情掉 -2~-8
    → 主动开口的分数打折（0.75 / 0.50 / 0.30）
    → 第 2 级允许问一句「你最近是不是很忙」

一轮结束（情绪真的动了）
    → 留一条余韵：「刚才他说『你烦不烦』，你还没缓过来。」
    → 4 小时 / 2 小时 / 3 小时 / 1 小时后自己淡掉
    → 你道歉 / 示好 → 软消，再留 30 分钟尾韵

下一轮开始
    → 心情 / 精力 / 时段 / 余韵 → 表达预算
    → 最多几条、多少字、能不能不接、几次之后强制回
```

三条回路各自独立。任何一条坏了，其余照常 —— 但你会感觉到"她有点不对"。

---

## 二、表达预算

| 心情 | 最多几条 | 整轮字数 | 不接许可 | 强制回阈值 |
|---|---|---|---|---|
| < 35 | 1 | 14 | 0.35 | 连续 3 次 |
| < 55 | 2 | 22 | 0.18 | 连续 3 次 |
| < 80 | 3 | 30 | 0.08 | 连续 2 次 |
| ≥ 80 | 4 | 40 | 0.03 | 连续 2 次 |

再叠两层：

- **精力 < 30** → 条数压到 1，字数 -6，不接许可 +0.10
- **凌晨 0–6 点** → 条数压到 1，字数 -4，不接许可 +0.10；
  23 点后条数不超过 2

余韵会再叠一次：冲突类 -1 条、-8 字、许可 +0.22。

### 为什么提示词里没有数字

system 里只出现一句定性的话：

> 这一轮你话不多。能一句说完的，不要拆成两条；不想接就真的不用接。

写「你心情 38」她会演；写「别拆两条」她会照做。
数值只用来算预算，不进提示词。

### 为什么"不回"不由代码决定

代码只调节 `silence_bias`（提示词里"你可以不接"的强度）。
真正不接，仍然是模型输出一个 `-`。

理由：代码掷骰决定不回，用户看到的是"她明明想了却没发"——
那是 bug 的味道，不是性格。

## 三、余韵

### 什么时候留

| 类型 | 判据 | 存活 |
|---|---|---|
| 冲突 | 有明确的推开词（"别烦我"/"闭嘴"/"随你便"…）且心情掉 ≥3 | 4 小时 |
| 受伤 | 心情掉 ≥5，或 sad / heartache 单根涨 ≥4 | 2 小时 |
| 担心 | worry 涨 ≥4 | 3 小时 |
| 暖意 | 心情涨 ≥4，或 sweet / happy 涨 ≥4 | 1 小时 |

小波动（±1~2）不留。一天写五条余韵，等于她一直在情绪里 ——
那不是人，那是没有情绪基线。

### 它长什么样

> 刚才他说「你烦不烦」，你还没缓过来。

带对象、带由头、不带数值、不下结论（不写"他不在乎你"）。
引用必须来自这一轮的原话，找不到就不引用。

### 怎么消

1. **你道歉 / 示好** → 软消。不删，改成
   「刚才那点别扭已经过去了，只是还有点没完全顺过来」，
   再留 30 分钟，负向预算撤掉。
2. **时间到** → 硬消。
3. **同类覆盖** → 只留最新一条（她不可能同时为两件小事别扭）。

同时最多三条。

### 关掉会怎样

关掉「余韵」插件（930）：她不再带着它说话，也不再说出来。
但余韵照常记录、照常衰减 —— 和「生活」同一个分层。

## 四、被无视

### 判据

主动消息发出 **8 小时**没回、也没被追问 → 算一次"被无视"。

比追问的 30 小时短很多：追问是"她还想说"，被无视是"她承认这次没接上"。

### 三件事同时发生

1. 心情掉：`moodDelta = -min(8, 2 + 条数×2)`，sad / worry 各加一点；
2. 等级 +1（上限 3），主动开口的分数乘 0.75 / 0.50 / 0.30；
3. 到第 2 级，允许一个 `check_in` 候选：分数 78 的
   「你最近是不是很忙」，24 小时只问一次。

### 为什么是打折，不是清零

分数打折会同时降命中率和排序，但**不把话说死**。
哪天真有很重的事（重要日期 88、未完话头 81），分数够高还能穿过去。

直接不给候选的话，她会连"你上次说要体检"都不提了 ——
那不是收敛，是坏掉。

### 怎么恢复

你出现一次，等级回落一级。但 `penalty_until`（6 小时）之前不赎回：
一次「在吗」消不完两次没回。

## 五、看日志

| 日志 | 含义 |
|---|---|
| `[预算] max2/22 chars, silence 0.18, force@3（心情偏低）` | 这一轮的预算被压了 |
| `[余韵] conflict：刚才他说「你烦不烦」，你还没缓过来。` | 刚留了一条 |
| `[余韵] 他哄了一句，气消了一半` | 软消 |
| `[主动] 2 条没人回，她心里沉了一下（被无视 2/3，主动分数 ×0.50）` | 被无视结算 |
| `[主动] 没说中（掷出 41 / 命中 28｜check_in…）` | 包括那句"你最近很忙吗" |

## 六、出问题先查什么

| 现象 | 先看 |
|---|---|
| 她突然话很少 | 「心情」页的分数；日志里 `[预算]` 那一行 |
| 她一直不主动 | `proactive.json` 的 `neglect_level`；是不是攒到 3 级了 |
| 她一直在生气 | `afterglow.json` 里是不是有没消掉的 conflict；`expire_at` 对不对 |
| 她不道歉也不消气 | `note_repair` 只认明确的道歉词，看看你那句在不在词表里 |
| 她说了不该说的天气 | `senses.json` 的 `at` 是不是超过一天了（超一天不认） |

数据坏了都不抛：`afterglow.json` / `senses.json` 是缓存型状态，删掉只会
让那一轮少一段，不会丢记忆和人格。
