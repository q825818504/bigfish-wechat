# 界面重构：生活气象观测

2026-11-09 起步，2026-11-10 补齐。把 `ui/` 从「浅色卡片后台」重构为
「她的今天 + 生活状态」的桌面控制台。

## 改动边界

- 保留全部 12 个导航页、QWebChannel 槽位、表单 id、保存/监听/发送/声音/记忆行为。
- 重塑外壳、导航、顶栏、色彩、字体、卡片、表单、弹窗与响应式规则。
- 新增只读桥接 `Backend.get_today()`，供「她的今天」读取真实生活状态。
- 不读取或写入 `D:\大肥鱼`；所有页面仍然只使用现有数据根和现有配置。

## `get_today` 返回什么

只读，不发模型请求，不写盘。

```json
{
  "ok": true,
  "day": "2026-11-09",
  "weekday": "一",
  "greeting": "晚上好",
  "life": {
    "asleep": false,
    "energy": 78,
    "doing": "把没看完的书收个尾",
    "condition": "醒着（精力 78）",
    "wake_at": "08:00",
    "bedtime": "23:30",
    "sleep_debt": 0,
    "plan_day": "2026-11-09",
    "trace": []
  },
  "plan": [
    {"at": "14:00", "what": "去楼下超市买点水果", "done": false,
     "done_by": "", "from": "self", "shareable": true}
  ],
  "mood": {"value": 72, "label": "心情不错", "reason": "…", "updated": "…"},
  "afterglow": {"count": 1, "text": "…"},
  "weather": {"line": "18°C，多云", "city": "杭州"},
  "journal": {"day": "2026-11-08", "text": "…", "days": ["…"], "path": "…"},
  "recent": [{"who": "阿澄", "text": "…", "dir": "in"}]
}
```

数据来源：

- `bigfish.life.load()`：生活状态、日程、当天轨迹
- `bridge_client.load_mood_only()`：心情
- `bigfish.senses.cached_weather()`：已缓存天气（不联网）
- `bigfish.journal.list_days()/read()`：本地日记
- `bigfish.afterglow.load()/active()/summary()`：余韵
- `Backend._recent`：最近收发的内存事件

没有数据时保持空态，不编造内容。

## 前端结构

```text
ui/index.html      壳层 + 12 页静态骨架 + 新「她的今天」
ui/style.css       旧的兼容层，保留现有组件和历史页面样式
ui/redesign.css    新设计系统；后加载，覆盖颜色 / 壳层 / 卡片 / 表单 / 页面布局
ui/app.js          在原有逻辑上增加 loadToday / renderToday / 顶栏时钟 / 新会话行
```

`redesign.css` 单独成层，是为了让旧页面在迁移期间仍有回滚路径；后续可以逐页合并回 `style.css`。
