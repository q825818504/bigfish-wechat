# 大肥鱼 · 生活气象观测 UI

基于大肥鱼 `0.11.x` 的 planning、README、现有 `ui/` 与后端代码，重新设计的一套桌面端高保真 UI。

**设计方向**：把“她的今天”做成生活气象观测，而不是通用 AI 控制台。深云杉导航、雾白纸面、整块雨蓝状态面、晨光时间带，用一条属于自己的生活时间线串起心情、精力、日程、记忆和关系。

## 直接看

- 设计总览板：`screens/00-design-board.png`
- 12 个主界面：`screens/01-overview.png` … `screens/12-logs.png`
- 11 个关键交互状态：`screens/13-chats-scope.png` … `screens/23-settings-snapshot.png`
- 可编辑原型：`index.html`
- 设计说明：[DESIGN.md](DESIGN.md)

## 运行原型

```bash
cd design/bigfish-ui
python -m http.server 8765 --bind 127.0.0.1
```

打开 `http://127.0.0.1:8765/`。

原型是纯静态 HTML/CSS/JS，不需要安装依赖，不连接真实后端，不读取 `config.json`、`data/`、聊天记录或任何真实数据。

## 原型交互

- 左侧 12 个导航页可切换。
- 记忆支持“她认定的事 / 原文记录 / 身份与主人 / 维护”四个子页。
- 设置支持“模型与回复 / 自动回复 / 版本与诊断”。
- 声音支持“什么时候出声 / 接入与音色 / 发送与回退”。
- 数据目录支持“位置与备份 / 清空与鲸落”。
- 会话齿轮打开三层作用域；心情“全部参数”打开高级参数；表情双击区域打开详情；设置“查看快照”打开请求快照；鲸落需要输入“鲸落”才能确认。
- 键盘：Enter / Space 触发按钮，Esc 关闭弹层，Tab 在弹层内循环。

## 验证

- Chromium 1440×1000，输出 2× PNG。
- 12 个主导航全部遍历，无 JS pageerror / console error / failed request。
- 四个子页组、五类弹层与鲸落确认均实际点击测试。
- 页面宽度未出现横向溢出；所有主页面内容在 1440×1000 内可见。
- 设计稿使用本地文件，不依赖在线字体、图片或 API。

## 数据与素材

- 人物“阿澄”、会话、记忆、数值、Key、音色 ID、路径全部为合成占位。
- 头像来自项目已有 `ui/icon.png`。
- 表情贴纸由 Agnes Image 2.5 Flash 根据头像生成，只作为设计素材；真实产品使用用户本地收藏。
- 未读取、修改或导出 `config.json`、`settings.json`、`plugins.json`、`data/`、`memory.sqlite3` 或真实聊天内容。

## 边界

这是可交互的高保真设计与前端原型，不是已经接入 PySide6 / QWebChannel 的生产界面；真实保存、监听、发送、声音、记忆查询仍需要后端桥接。生产落地建议见 [DESIGN.md](DESIGN.md) 的“接入现有 Qt WebEngine”一节。
