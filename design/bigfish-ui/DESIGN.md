# 大肥鱼 UI 设计系统

## 1. 设计论点

**她不是等待 prompt 的模型，是一个正在过日子的人。**

界面必须先回答“她此刻怎样、今天在做什么、最近发生了什么”，再回答“怎么改参数、怎么排查发送”。因此首屏不做 KPI 驾驶舱，而做“她的今天”：一条光线时间带，一块情绪天气，一张今日日程和两段最近对话，旁边才是运行状态和发送通道。

未采用的旧方向：浅蓝卡片后台、通用 AI 紫色渐变、深色霓虹控制台、纯角色立绘首页。它们分别丢失了生活感、隐私感、可读性和管理入口。

## 2. 视觉识别

### 2.1 色彩

| 角色 | Token | 值 | 用法 |
|---|---|---|---|
| 外壳 | `--sidebar` | `#153B38` | 主导航、深色状态面、只读快照 |
| 页面底 | `--workspace` | `#F4F6F0` | 工作区背景 |
| 纸面 | `--surface` | `#FBFCF8` | 内容卡、表格、表单 |
| 雾面 | `--surface-2` | `#E8EFEA` | 次级面板、输入底色、状态块 |
| 正文 | `--ink` | `#182522` | 主要文字 |
| 次级 | `--muted` | `#5E706A` | 说明、标签 |
| 弱化 | `--faint` | `#68776F` | 时间、来源、脚注 |
| 主操作 | `--teal` | `#2F6B61` | 保存、启动、选中 |
| 天气 | `--rain` | `#6F93A2` | 她的今天、心情主状态面 |
| 晨光 | `--sun` | `#DCB25C` | 当前时刻、提醒、强调 |
| 暖余韵 | `--rose` | `#B9756B` | 余韵、情绪、关系摩擦 |
| 生态 | `--leaf` | `#5D7E65` | 正常、完成、可共享 |
| 危险 | `--danger` | `#9E443D` | 清空、鲸落、错误 |

一个界面只承担一种主张：深青负责归属，雨蓝负责她的当下，晨光负责此刻，暖色负责情绪。状态色只表达状态，不做装饰。

### 2.2 字体

- 字族：`Segoe UI Variable Display / Text`，中文回落 `Microsoft YaHei UI / Microsoft YaHei`。桌面 Operate 场景优先使用系统 UI 字族，保证 QWebEngine 和 Windows 上稳定、清晰、无需网络字体。
- 显示：29 / 25 / 21 / 16 / 15.5 / 13px，字重 620–660，字距 -0.012 至 -0.05em。
- 正文：12.5–13px；密度高的表格与元数据为 10–11.5px，属于桌面高密度场景的次级信息。
- 数字统一 `font-variant-numeric: tabular-nums`，时间、字数、分数和统计列不会抖动。
- 仅日志、注入原文、路径和代码使用等宽字族，不把等宽当“技术感”装饰。

### 2.3 空间与形状

- 基准网格：4px；页面内边距 30px；区块间距 18px；组件内 6/8/11/14px。
- 卡片圆角 18px；弹层 18px；输入 / 按钮 8–10px；标签 5–7px。
- 卡片以背景色差分层，不用重阴影；仅弹层和 toast 使用阴影。
- 1px 规则只用于真实表格行、表单边界和导航分隔，不用细线做装饰。

### 2.4 图标与图形

- 全部图标为同一套 1.7px 描边的内联 SVG symbol，不使用 emoji。
- 天气、太阳、云、波形为功能图形，不是装饰插画。
- 角色头像沿用项目已有 `ui/icon.png`，保留产品识别。
- 表情收藏使用 AI 生成的 4×3 粉彩贴纸示例；真实产品替换为用户自己的本地收藏。

### 2.5 动效

- 页面切换：`translateY(7px) + opacity`，280ms，`cubic-bezier(.2,.75,.2,1)`。
- 弹层：200ms 上浮 + 轻微缩放；toast 200ms。
- 按钮/导航：背景与颜色 150ms；按压位移 1px。
- `prefers-reduced-motion` 下全部压缩到 0.001ms。
- 没有循环装饰动画、视差或自动播放。

## 3. 壳层与导航

```
232px 深青侧栏
├─ 品牌 / 头像 / v0.11.2
├─ 运行：概览、会话
├─ 她：灵魂、心情、记忆、印象、表情包、声音
├─ 系统：数据目录、插件、设置、日志
└─ 运行中 / 示例账号 / 本机隐私

64px 顶栏
├─ 大肥鱼 / 当前页面
├─ 界面示例 · 非真实数据
├─ 日期与时间
└─ 刷新 / 运行提醒

工作区
└─ 12 个页面（头部 + 内容 + 页面级脚注）
```

侧栏在窄窗口收缩为 76px 图标栏，760px 以下完全隐藏，内容区改为单列。桌面产品的运行环境不低于 1024px；移动适配只保证窄窗口可用，不把角色控制台伪装成手机应用。

## 4. 页面结构

### 概览 / 她的今天

- 首屏主状态：头像、早上好、心情、精力、醒来时间、关系阶段、天气与“此刻在做”。
- 今日光线带：06:00–24:00 的分段色带；当前时刻用晨光标记，不显示假的连续折线。
- 今日安排：3 条，标注“接着昨天 / 她自己排的”。
- 最近发生：两段用户与她的对话；用户气泡在左、她的气泡靠右，各自带说话人标签，发送账本可以对照。
- 运行状态：运行中、发送通道就绪、监听会话、已运行时长。
- 运行环境：管理员、桌面解锁、微信、数据库密钥、模型、语音气泡分别成行。
- 今日细节：今天她记住的、她的日记、明天想接着做。
- 日记只出现在概览入口和本地目录，不新开第 13 个侧栏。

### 会话

- 账号卡片显示当前账号、WXID、监听和可读会话。
- 分组：全部 / 联系人 / 群聊 / 公众号；群聊标注触发策略。
- 监听开关与齿轮分开：切开关不改监听；齿轮只打开作用域。
- 作用域：全局 → 微信账号 → 单个会话；五项（处理自己消息、群聊只回被叫、无条件群、回复长度上限、安静时段）有继承 / 开 / 关三态。弹层逐行显示“本会话覆盖 / 继承自账号”，覆盖行铺暖光底，底部动态写“1 项本会话覆盖 · 4 项继承”。
- 页头主按钮是“保存监听”，刷新和选择账号都是次按钮；表格底部只显示已保存状态。
- 发送三态：sent / failed / unknown，unknown 明确不自动重发。

### 灵魂

- 身份三字段（名字、称呼、别名）。
- 人格正文是可写文本域，保留字数预算和保存状态。
- 珍视条目有锁，锁住的条目不能直接删。
- 四项性格滑杆将数值翻译成一句人话，而不是展示模型不理解的数字。
- 自我笔记区分手写与自动复盘，自动条目带日期并可删。
- 注入预览显示各段字数和比例，不把整段 prompt 塞进首屏。
- 保存动作位于页头，避免底部重复操作栏。

### 心情

- 主状态是 72/100 + “心情不错 · 晴间多云”，原因是真实对话由头。
- 七维：开心 / 踏实 / 甜蜜 / 心疼 / 担心 / 难过 / 吃醋，全部统一 0–100 标尺。
- 表达预算：最多 3 条、30 字、可不接 0.08、连续 2 次强制回；说明它们来自心情、精力、时段与余韵。
- 余韵单独显示，不混入七维分数。
- 参数区显示基线、半衰期、每日注入次数、注入方式；高级阈值和自动判断放入弹层。
- “这句话会进入下一轮”直接展示实际注入文本，避免数值化播报。

### 记忆

- 默认事实层，带有效 / 已取代 / 已忘掉状态、归属、可见性和来源。
- 右侧详情：真实原话来源、置信度、使用次数、纠正链。
- 文案明确：删原文 ≠ 忘事实；忘掉只让结论失效。
- 原文页是独立视图，支持角色筛选、搜索、删除与会话记忆。
- 身份页将“新建平台身份”和“身份组挂接 / 摘下”分开；跨平台合并不搬事实、不删原记忆。
- 维护页有导出、导入、压缩和修索引。
- 其他记忆池只给数量，不铺内容。

### 印象

- 左侧人物列表，主人固定第一位。
- 主卡：画像、手写评语、开放信息。
- 右侧：称呼 / 没说出口的话（带原话依据）、关系事件时间线。
- 隐私边界条：她会说出去、她不会说出去、关系卡依据，用真实白名单术语。
- 阶段是描述，不是好感度；不做等级、进度条、解锁权限。

### 表情包

- 4 列封面网格，每张有名称、情绪和强度；一页 12 张，18 张时确实有第二页。
- 右侧显示选中表情、文件、最近发出、编辑说明和试发；网格与详情读同一份 `mood` / `strength` 字段。
- 插件开关与频率明确归“插件”页，当前页只负责收藏。
- 导入统一转 GIF、去重、部分失败的说明留在页面里。

### 声音

- 深色声音主状态：她用自己的声音，但不会把同一句念两遍。
- 三个子页：什么时候出声 / 接入与音色 / 发送与回退。
- 六种策略、命中率、冷却、每日上限、连续上限、场景白名单。
- 接入页：Breeze TTS、Key、示例音色身份 `薄荷 · 明亮少女音 / bf_acheng_v1`、语言、音色基线、固定语速；首页元信息与主状态卡显示同一组音色名和 ID。
- 回退链：合成失败 / 超 50 秒 → 文字；气泡未按录音键 → 退同一份 WAV；已按录音键 → 结果未知，不补文字。
- 气泡未配置只显示为警告，不阻断文字回复。

### 数据目录

- 当前路径、可写性、默认 / 自定义、打开目录。
- 这里就是她：soul.json、mood.json、memory.sqlite3、journal、stickers。
- 搬迁：搬过去（复制成功才改指向）与只改指向分开；恢复默认不删旧目录。
- 清空：保留灵魂和人格，删心情、记忆、印象；自动备份。危险页使用纸面 + 红字，不再用整块红底。
- 鲸落：全删；必须输入“鲸落”并二次确认，强制备份。使用整块深红面、纸白主按钮，视觉重量明显高于清空。
- 危险页先显示“动手之前”的目录 / 备份 / 可写性，再并排两个不同层级的操作，最后说明“执行之后”留下什么；页签与主体内容一一对应。

### 插件

- 列表带座位、类型、可调参数数量与开关。
- 右侧显示生活插件为什么需要、会影响什么、不会做什么、实际注入原文、可调参数。
- 底部身份序：850 记忆 / 860 灵魂 / 870 生活 / 872 日程 / 890 说法 / 895 声音 / 900 心情 / 930 余韵 / 9990 守卫。
- 内建段不可关；插件只能填空位；开关只有用户能改；下一轮生效。

### 设置

- 模型、自动回复、诊断三个页签。
- 模型：渠道、Key、接口、真实模型列表、协议、温度、token、测试连接、模型健康。
- 一次回复怎样发生：收到 / 拼装 / 发送，让诊断路径有结构。
- 诊断：请求快照最近 20 份、段落字数占比、目录可写、旧格式、查看 JSON / 目录。
- 更新：当前 / 最新版本、发布时间、说明；自动更新仍注明端到端限制。

### 日志

- 时间、类型、事件和结果四列；颜色按事件类型区分。
- 筛选：收发 / 心情关系 / 生活 / 声音 / 异常。
- 右侧解释“预算 / 余韵 / 主动 / 声音”各自代表什么，不把日志变成装饰图表。
- 发送 unknown 的三态规则在日志页重复一次，因为这是最容易误操作的地方。

## 5. 组件规范

| 组件 | 规范 |
|---|---|
| 主按钮 | 深青实底，白字，10px 圆角；只用于保存 / 启动 / 移动等明确动作 |
| 次按钮 | 纸面、1px 边线；用于打开、切换、导出 |
| 危险按钮 | 深红实底；清空与鲸落分级使用 |
| 标签 | 5–7px 圆角，语气色 + 文字，不做纯色状态点唯一标识 |
| 开关 | 32×18，轨道与滑块；状态不依赖颜色单独传达 |
| 输入 | 36px 高，1px 线，8px 圆角；聚焦时深青边 + 2px 半透明焦点环 |
| 表格行 | 无卡片嵌套，1px 行线作为真实数据分隔，hover 仅换底色 |
| 弹层 | 18px 圆角，40% 遮罩，唯一阴影；Esc / 遮罩关闭，Tab 循环 |
| 空状态 | 图标容器 + 一句事实 + 一句下一步；不把所有空都画成错误 |
| Toast | 深青底、2.8 秒自动消失；只用于确认，不承载需要保留的错误 |
| 危险确认 | 需要输入指定词，按钮明确写“确认鲸落”而不是“确定” |

## 6. 状态与边界

设计稿覆盖：

- 运行中 / 发送通道就绪分离
- 未保存、保存中、保存失败
- 空人物、空事实、空表情、空声音、空日志
- 不可写数据目录 / 迁移失败不改指向
- 语音气泡未配置
- 发送 sent / failed / unknown
- 记忆 active / superseded / forgotten
- 可见性 private / shared / public + 话题白名单双闸门
- 鲸落输入确认
- 旧格式快照、trace 关闭、目录不可写

真实产品仍必须接后端。这个原型里所有“保存成功”的 toast 都是演示反馈，不会写配置；所有示例内容都是合成数据。

## 7. 无障碍与桌面习惯

- 所有按钮可键盘聚焦；焦点环使用晨光 2px。
- 弹层有 `role=dialog`、`aria-modal`、焦点循环与 Esc 关闭。
- 图标按钮均有 `title` 或 `aria-label`；图标不作为唯一信息。
- 正文和次级色提升到高对比；弱化色专门用于时间、来源和脚注。
- 状态不只靠颜色：标签带文字，发送三态带文字，记忆状态带文字。
- 支持 `prefers-reduced-motion`。
- 触控尺寸在桌面鼠标场景偏紧凑；若要支持平板，按钮提升到 44px。

## 8. 接入现有 Qt WebEngine

1. 保留现有 `ui/index.html` 的 QWebChannel 脚本，把壳层、页面和组件类迁移到 `ui/style.css` / 新页面模块。
2. 把 `pages.js` 中的合成数据替换为现有 bridge 返回值；尤其保留 `get_status`、`get_chat_scope`、`memory`、`list_plugins`、`voice`、`prompt_trace` 的字段语义。
3. 不要直接替换 `ui/`：先在设计目录评审，再用 feature flag 切到新界面；旧页保留一轮回滚。
4. 所有后端字段仍按现有白名单读写；不要在前端新增对模型、可见性或危险操作的隐式修改。
5. 语言包和字体都走本地；不要引入 Google Fonts 或在线图片。
6. 动态大列表（表情、记忆、日志）需要沿用分页 / 局部刷新；当前设计稿只渲染首屏示例。
7. 生产前把示例头像、贴纸和“界面示例”提示替换为真实资产和真实状态；不能把示例文案当真实用户数据。

## 9. 设计审阅记录

- 方向：concept-seed `assigned`，seed reference `seed:30425f53f0de1989`。
- 选定的 grounded direction：生活气象观测。
- 被拒绝的六个 catalog challenger，以及只保留的纪律：单次状态更新、收藏网格、共用标尺、固定时间列、真实状态、查看局部时保留全局上下文。
- 浏览器：Chromium 1440×1000，2× PNG；12 页及 11 个次级状态全部通过导航 / 子页 / 弹层交互测试，无 console error、pageerror 或 failed request。
- 机械检测：impeccable detect 无阻断项；design-taste lint 0 FAIL / 0 WARN。真实表格行线、表单边界、弹层阴影与日志等宽均按功能用途标注，不用装饰性阴影或 kicker。
- 无障碍冒烟：无名称按钮 0、无 alt 图片 0、12 个导航页无横向溢出；1280×800 窗口同样没有横向滚动。
- 独立视觉验收结论为 fix，8 条均已处理：概览对话说话人、作用域覆盖/继承、危险层级、表情字段与页容量、音色示例 ID、危险页页签一致、会话主按钮、会话与插件纵向留白。视觉世界、导航、色彩与字体未改。
- 当前不足：这是高保真前端原型，非生产接入；真实数据密度、窗口缩放和 QWebEngine 字体渲染仍需在现有桌面程序内做一轮回归。
