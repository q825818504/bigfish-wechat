同一个人的多个账号

—
为什么需要这一步。 你在微信是 wxid_xxx，在 B 站是 UID 12345， 在抖音是另一串数字 —— 这些在各自平台里就是三个账号， 没有任何技术手段能可靠地把它们认成同一个人 （昵称会撞会改，头像能换，让模型判断更是灾难）。
所以这里只由你手动认领。把两个平台账号挂到同一个身份组下， 她才会在微信里想起你在 B 站说过的话。

认领之后不会发生什么： 已经记下的事实不会搬家（归属稳定）， 别人的私密仍然看不到 —— 认领只影响"你自己的账号之间"，不影响"别人能不能看你"。
没聊过的 id 会自动建一条记录；挂上去后她的记忆就会跨平台汇总。

什么时候出声

默认预演。命中语音后只发语音，不会再发同内容文字。
气泡会按住微信录音键 + 把音频播进 CABLE Input；文件不需要虚拟声卡。
选 CABLE Input；微信麦克风要选 CABLE Output。只在气泡模式用。
必须和微信「设置 → 快捷键 → 发语音」完全一致；程序负责按住和松开。
0.2 = 五次里大约一次。模型明确写 [[voice]] 时不受它限制。
同一会话两条语音之间至少隔多久。0 = 不冷却。
0 = 不限。控制积分消耗的最后一道闸。
连着几条语音后强制换文字。0 = 不限。
默认 220 字，约 45–50 秒；合成后超过 50 秒也会自动改文字。
没勾的场景一律发文字。拌嘴默认不勾：文字更稳，也不容易把气话念成撒娇。
代码、网址、表格念出来没有意义；模型标记不会被对方看到。
群聊默认关闭。群里语音文件没有 @ 关系，别人也不知道在念给谁。

只要命中语音，就只发语音，不再发同内容文字；语音上限 50 秒 （微信上限 60 秒，留 10 秒容错）。
当前发送形式是 音频文件，不是微信原生语音气泡。个人微信协议不支持 发语音消息；要做语音气泡得用虚拟声卡 + UIA 录音，链路另开。 所以默认「先文字，再语音」：对方不点文件也能看懂内容。
