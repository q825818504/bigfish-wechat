修重复发送：UIA 成功之后又走了一遍兜底

真机日志：
    发送后新增 2 条
       · type='动画表情' sender_id=4
       · type='动画表情' sender_id=4
    耗时 12.6s（正常约 6s）

一次调用发了两条。原因是兜底条件写错了：

    ok = self._paste_media_uia(...)
    if ok:
        pass                                # 成功了，但什么都没做
    if not err or err.startswith(...):      # err 还是空字符串 → True
        gui.send_file(...)                  # 又发一次

`err` 在成功路径上从来没被赋值，所以 `not err` 恒真。

改成 uia_ok 显式记录，兜底只在它为 False 时跑。

另外 sender_id=4 而不是 2 —— 这印证了上一个提交的判断：
vendor 那句 `sender_id != 2` 在这台机器上会把所有自己发的消息
过滤掉，验证函数必然返回 False。

真机结果（修之前）：7/7 通过，但发了两条。
修完之后应该只发一条。
