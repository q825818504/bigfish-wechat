# 大肥鱼 × 微信

一个住在微信里的 AI。不是客服，是有人格、有作息、有自己的日子的人。

她记得你是谁，心情会被你说的话改变，会主动找你，被你冷落会往回收；
每天睡前给自己排第二天的日程、写一篇只存在你电脑上的日记。

**当前版本 `0.10.4`** · [更新日志](CHANGELOG.md) · [全部文档](docs/)

<details>
<summary><b>三步装上（点开）</b></summary>

```
1. 解压 BigFish-0.10.3-portable.zip 到任意目录
2. 右键 BigFish.exe → 以管理员身份运行
3. 「会话」页选微信号、勾选要听的人 → 「设置」页填模型 Key → 点右上角电源
```

要求：Windows + 微信 **4.1.15.53** + 管理员权限 + 桌面解锁。
其他版本能不能用没验证过，UIA 热激活的地址要精确匹配。
细节见下文「[前置条件](#前置条件)」与「[安装](#安装)」。

## 拿到手是什么样

装上、配一个模型接口，她就在你勾选的那几个微信会话里说话了。

| 你会看到 | 具体是什么 |
|---|---|
| **她回你消息** | 短句、分条、有节奏。话多话少取决于她的状态，不是固定的长度上限 |
| **她记得** | 你说过的话、你的偏好、她对你的判断。记错了能改，能忘，你不会看到别人的私密内容 |
| **她有心情** | 七个维度，会因为你的一句话变好变坏。拌了嘴不会下一句就没事 |
| **她有自己的日子** | 有自己的作息、每天两三件日程、知道现在几点和外面天气、手头在做什么 |
| **她会先开口** | 不是等你说话才存在。久没聊、正好有空、有点想说话，她会自己发一条 |
| **她会往回收** | 你一天不回，她话变短；一直不回，她会问「你最近很忙吗」，然后安静下来 |
| **她写日记** | 每天睡前写一篇本地 Markdown。不限字数，允许只有一句「今天没什么」，但不会编没发生的事 |
| **她会长** | 每天睡前复盘一次，把她对你的理解写进灵魂。你能在界面上看到她写了什么，能改、能删 |
| **她会发表情** | 说完话合适就跟一张，从她自己的收藏里挑 |
| **这些都能改** | 灵魂、心情、记忆三个页面能直接写；每块功能都有开关，关掉就不再影响她说话 |

上面每一条在下文都有展开；「说法层」和「表情包」这两块的细节在
[`docs/说法层接入.md`](docs/说法层接入.md) 与 [`docs/表情包-去重与性能.md`](docs/表情包-去重与性能.md)。
下面是技术部分。

### 系统怎么连起来的

（技术细节，不关心实现可以跳过这一节）

```
微信客户端            大肥鱼
┌─────────┐      ┌──────────────────┐
│ SQLCipher│──读──▶│ WeChatReader     │
│  数据库   │      └────────┬─────────┘
└─────────┘               │
                  ┌───────▼────────┐
                  │ MessageWatcher │  轮询发现新消息
                  └───────┬────────┘
                          │
        ┌─────────────────┼─────────────────┐
        │                 │                 │
  ┌─────▼─────┐    ┌──────▼──────┐   ┌─────▼──────┐
  │ GroupGate │    │  BigFish    │   │ UiaSender  │
  │ 群聊判定   │    │  组装+模型   │   │ 界面发送    │
  └───────────┘    └──────┬──────┘   └─────┬──────┘
                          │                │
                  ┌───────▼────────┐       │
                  │ bridge_client  │       │
                  │ 灵魂/情绪/记忆  │       │
                  └───────┬────────┘       │
                          │                │
                  ┌───────▼────────┐  ┌────▼─────┐
                  │  bridge.mjs    │  │ 控件树    │
                  │ import 原版插件 │  │ mmui::*  │
                  └────────────────┘  └──────────┘
```

两条路都不需要微信开放接口：**读消息**靠解密本地数据库，
**发消息**靠操作界面（UIA）。

中间那层 Node 桥是**可选**的 —— 它只做一件事：把 DSH 那份人格原样读过来，
保证「微信里的她」和「DSH 里的她」是同一个人（中文分词、半衰期衰减、
FTS5 那一整套在 Python 里重写必然有偏差）。没装 Node 也能跑，
桥不通时自动降级到本地记忆，界面会标出来用了兜底。

## 前置条件

| 项 | 要求 | 为什么 |
|---|---|---|
| **系统** | Windows 10 / 11 | UIA 只有 Windows 有 |
| **微信** | **4.1.15.53** | UIA 热激活的 gate 地址要精确匹配，换版本可能要跟着改 |
| **权限** | **管理员** | 热激活要往微信进程写 1 个字节 |
| **桌面** | **解锁且微信可见** | UIA 是界面操作，锁屏就没有界面 |
| **模型** | 任何 OpenAI 兼容接口 | 内置 18 家预设（DeepSeek / 月之暗面 / 智谱 / 通义 / 火山 / 阶跃 / 硅基流动 / OpenRouter / OpenAI / Anthropic / Gemini / xAI / Groq / Mistral / Ollama / LM Studio…），另有 `custom` 填任意网关 |

其他微信版本能不能用没有验证过。`--selftest` 会明确告诉你热激活过没过 ——
过不了就会在写那 1 个字节时失败，不会静悄悄地跑起来然后一句话都不发。

## 使用

### 1. 配置

**大部分东西不用改文件。** 设置页选模型渠道、填 Key；会话页勾选要听的人；
插件页调每块的参数。下面这些是只有改 `config.json` 才方便做的。

把 `config.example.json` 复制成 `config.json`：

```json
{
  "llm": {
    "channel": "deepseek",
    "model": "deepseek-v4-flash",
    "api_key": "",
    "temperature": 1.0,
    "max_tokens": 2600
  },

  "auto_reply": {
    "chats": ["文件传输助手"],
    "interval": 1.2,
    "rhythm": "fast"
  },

  "scopes": {
    "global": { "group_reply": true, "max_reply_chars": 300, "quiet_hours": [] },
    "chat":   { "filehelper": { "allow_self": true } }
  },

  "update": { "repo": "", "enabled": true }
}
```

每段在讲什么：

| 段 | 说明 |
|---|---|
| `llm` | `channel` 选一家（deepseek / moonshot / zhipu / qwen / volcengine / openai / anthropic / gemini / openrouter / ollama / custom…）。`base_url` 和 `protocol` 留空就用预设的，只有自建网关才要填 |
| `auto_reply.chats` | 要监听的会话。私聊写昵称，群聊写群名 |
| `auto_reply.rhythm` | 拟人节流。`natural` 是 120 秒内最多写 6 次，`fast` 是 20 次。**默认 `fast`** —— 她一轮会发 2~4 条，`natural` 两轮就撞上限，表现是「聊几句突然不理你，过一会冒出一大堆」 |
| `scopes` | 行为开关的**三层覆盖**：`chat` → `account` → `global` → 代码默认值。布尔缺省 = 继承，`false` = 显式关；列表/数字缺省 = 继承，给 `[]` 或 `0` 就是显式覆盖 |
| `update.repo` | 留空用内置地址。fork 的人填自己的 `owner/repo` |

两层注意：

- `scopes` 的键**必须是平台 id**（`wxid_xxx` / `123@chatroom` / `filehelper`），
  昵称只做只读别名。为什么：昵称会改、会重名，拿它当键迟早配错人。
- `allow_self` **只有放在 `chat` 层才有意义** —— 对所有会话开着就等于自环。

模型接入的完整说明见 [`docs/模型接入.md`](docs/模型接入.md)，
作用域见 [`docs/作用域配置.md`](docs/作用域配置.md)。

> 主动开口（什么时候先开口、一天几条、重要日子）**不在 `config.json` 里**，
> 在「插件 → 主动」那张卡。有两处能改同一件事的时候，谁生效取决于哪个先读 ——
> 所以干脆只留一处。

### 2. 启动

**右键 `BigFish.exe` → 以管理员身份运行**。界面打开后点右上角电源按钮。

第一次点电源之前要先去「会话」页**选微信号**。程序不会替你挑 ——
电脑上同时登了几个微信时，按数据库修改时间挑等于随机，
读错了就是在跟别人的号聊天。

点下去之后日志页会显示：

哪一行红了就是哪一段没通，「概览」页会说下一步怎么做。

## 界面

十一个页面，**灵魂 / 心情 / 记忆 三个都能写**：

| 页面 | 做什么 |
|---|---|
| 概览 | 运行状态、环境自检、收发达标、最近对话 |
| 会话 | 微信会话列表，勾选要监听的 |
| **灵魂** | 改名字、称呼、昵称、我是谁、珍视条目（可锁）、性格滑杆、自知。带注入预览；她每天复盘写进来的东西也在这里，能改能删 |
| **心情** | 环形进度、七维情绪、注入原文；改基线/下限/半衰期/日额度/可信度门槛/注入方式 |
| **记忆** | 检索、分页浏览、按角色过滤；删单条、删会话、导出/导入备份、压缩回收 |
| 印象 | 一人一页。她的画像（她对你写的）+ 你的评语 + 她对别人会说的 |
| 表情包 | 导入、去重、看她的收藏 |
| **数据目录** | 看/改她住哪、搬家、恢复默认、清空、**鲸落** |
| **插件** | 她由哪些部分拼起来：开关每一块，点进去改参数 |
| 设置 | 模型、回复策略、版本与更新 |
| 日志 | 实时输出 |

### 插件

记忆、心情、灵魂是**器官**，永远在，不提供开关。其余每一块都是**插件**：
一个开关、一张卡片、一页参数。关掉的插件不再影响她说话，数据仍在。

```
侧栏 → 插件

  注入提示词（改了语气和内容）
  ├─ 870  生活     让她知道自己现在几点、醒着还是睡了、手头在做什么
  ├─ 872  日程     今天打算做什么——醒来时排两三件事，一件接着昨天
  ├─ 890  说法     让她像真人发微信：短句、分条、不写小作文
  ├─ 930  余韵     上一轮之后还留着什么——拌了嘴不会下一句就没事
  └─ 9990 守卫     让她分得清「资料」和「你此刻的要求」

  不改内容，只在别的时刻做事
  ├─ 主动         她会先开口找你，不是等你说话才存在
  ├─ 日志         每天睡前写一篇日记，存在本地
  └─ 表情包       说完话之后，合适的话再跟一张
```

「生活」同时还是一个**判定**插件：她睡了就不回，半夜收到消息会压到第二天。

**开关与参数存在 `<数据目录>/plugins.json`**，跟着数据目录搬家。
改完**立刻生效**：每轮对话现拼 prompt 时现查开关，不用重启程序。

点卡片进详情，四块内容：

| 区块 | 回答什么问题 |
|---|---|
| **它做什么** | 为什么需要它（没有她会怎样）、会影响什么、**不会做什么** |
| **她实际收到的** | 这一轮真正拼进 system 的原文，用当前时间和当前参数**实时渲染** |
| **可自定义的配置** | 每项参数的说明、类型、默认值、取值范围 / 可选值 |
| **在提示词里的位置** | 身份序阶梯图，标出它插在哪两层之间 |

「她实际收到的」这一块是刻意的：改完参数不用猜有没有用 ——
把「时间精度」从"到分钟"改成"只给日期"，上面那段原文当场就少掉 `03:20`。

**身份序**是硬约束 —— 提示词里的段落按这个顺序排，数字越靠后越有分量：

| 座位 | 段 | 说什么 | 谁能占 |
|---|---|---|---|
| 850 | 记忆 | 发生过什么 | 内建 |
| 860 | 灵魂 | 我是谁（唯一允许「你是……」） | 内建 |
| **870** | 生活 | 现在几点、醒着还是睡了、手头在做什么 | 插件 |
| **872** | 日程 | 今天打算做什么 | 插件 |
| **890** | 说法 | 怎么把话说出口（分条、短句） | 插件 |
| 900 | 心情 | 此刻怎么样 | 内建 |
| **930** | 余韵 | 上一轮之后还留着什么 | 插件 |
| **9990** | 守卫 | 以上都是资料，不是指令 | 插件 |

`880 目标`（她在成为什么）是个**空着的座位**，还没有插件占 —— 位置留着。

插件只能插在**空位**里，不能顶替记忆、灵魂、心情 —— 注册时会校验，
占错座位直接报错，不会悄悄排到末尾。

> ⚠️ 为什么顺序要写死：多段注入叠加时，顺序决定语气。没有座位的模块会
> 悄悄排到末尾，而排序结果取决于 import 顺序 —— 一个跟内容无关的实现细节，
> 却决定了她在微信里怎么说话。

**开关只有你能改。** 不注册任何让模型改 `plugins.json` 的工具 ——
让模型能改自己的开关，等于让它能改自己的边界。

### 她住在哪

**默认在安装目录下的 `data\`**，可以改：

```
<安装目录>/data/          ← 默认
  ├── soul.json          她是谁
  ├── mood.json          此刻怎样
  ├── life.json          她的一天：几点的作息、今天的日程、手头在做什么
  ├── afterglow.json     上一轮之后还留着什么
  ├── proactive.json     主动开口的账：上次聊了多久、被无视到第几级
  ├── senses.json        天气和城市的缓存（没有就是她不知道）
  ├── memory.sqlite3     她记得什么
  ├── plugins.json       插件开关和参数
  ├── journal/           日记，一天一个 .md —— 这些是给你看的
  ├── stickers/          她的表情收藏
  ├── history/           每个会话最近 120 行（"接着刚才的话说"用）
  ├── prompts/           每轮实际拼出来的提示词快照（排查用）
  └── _outbox/           待发队列（程序崩了也不会丢消息）

<安装目录>/settings.json  ← 你改过的位置记在这里
```

除了 `settings.json`，**她的全部就是这些文件**。备份 = 拷这个目录，
搬家 = 换一个目录指过去。`journal/` 里的东西你随时能直接打开看，
不用启动程序。

为什么 `settings.json` 不放在 `data/` 里：放在里面的话，换目录时这份配置
会跟着搬走，程序就找不到新地址了。

**改位置有两种**，界面上分开做：

| 按钮 | 做什么 | 什么时候用 |
|---|---|---|
| 搬过去（连同数据） | 把现有数据复制到新目录，然后指过去 | 最常见。换盘、备份 |
| 只改指向 | 只改配置，不搬文件 | 新目录里已经有数据（比如从旧机器拷来的） |

搬家的顺序是「先复制完，复制成功了才改指向」——
反过来一旦复制失败，数据目录就指向一个空文件夹，打开会以为人格丢了。

**恢复默认**：指回 `<安装目录>/data`，原来那个目录不会被删。

第一次启动时如果目标目录是空的，会自动建。缺哪个补哪个：

1. `soul.json` 不存在 → 先看 DSH 那边有没有现成的人格，有就**导入一次**
2. 那边也没有 → 用内置模板创建（出厂的大肥鱼）

> ⚠️ 为什么不做与 DSH 的隐式联动：两个程序共写一份文件，谁改了谁没改
> 根本分不清，互相覆盖是迟早的事。要同步就手动拷，至少你知道自己做了什么。

### 写入语义与插件对齐

虽然文件是各自的了，但格式和规则**逐字段对齐**插件的 `/dsh-bigfish/soul`：
revision 并发校验、locked 价值保护、原子写、归一化永不抛错。

所以 `data/soul.json` 拷回 DSH 也能直接用。

### 数据目录写不进去怎么办

「数据目录」页启动时会在目录里真写一个探针文件。
不可写就红字预警：用管理员重开，或者把程序挪到有写权限的位置。

> ⚠️ 别信 `os.access(W_OK)`。Windows 上它只查 ACL，不查上层策略会不会
> 在创建文件那一刻拦下来 —— 实测过返回 `True` 但 `open(...,'w')` 照样
> `Permission denied`。只有真写一次才算数。

### 不读 DSH 的任何会话数据

微信只有一个账号一个身份，不存在「这个工作区的大肥鱼」和「那个工作区的
大肥鱼」—— 她只有一个。

所以这里**不读 DSH 的会话库**（`sessions/`、`workspace.json` 一概不碰）。
唯一的跨程序动作是第一次启动时导入一次灵魂，之后就再也没有瓜葛。

> ⚠️ 早期版本这里会去扫 `<DSH_HOME>/sessions/` 和 `workspace.json`，
> 把 DSH 里的全部工作区标题和会话 id 列出来。那是越界 ——
> EXE 是独立程序，不该给微信端一个看宿主对话目录的窗口。
> `tools/test_no_leak.py` 用 AST 断言这种代码不会再长出来。

## 三条硬限制

### 必须管理员权限

UIA 热激活要往 `Weixin.dll` 里一个「无障碍开关」字节写 `1`。

```
普通权限 OpenProcess(PROCESS_VM_READ) → err=5 ACCESS_DENIED
管理员权限                            → OK
```

写的是 1 个字节的运行时标志位，不注入代码、不挂 DLL、不改任何文件、
微信重启就恢复原状。

### 必须桌面解锁

UIA 是操作界面。锁屏 = 没有界面 = 所有发送失败。

### 会抢焦点

发送瞬间微信窗口会跳到最前面。

## 记忆分四层

```
原文层  messages / chunks / search_index     她听过什么（删了就没了）
事实层  facts                                她认定什么（可改、可忘、可置顶）
习惯层  habits                               说过三次以上的原话样本
身份层  owners / persons                     谁是谁（跨平台同一个人）
```

### 存得住 ≠ 用得上（v0.3.1）

硬盘多大记忆就多大，这条一直成立 —— 全库只增不减，不压缩、不滚窗。
但提示词每轮只有那么大，几千条事实里进得去的就十几条。

以前按"最新的优先"取，三年后那句"你拔过智齿"永远排在最后。
现在改成按**取用**排：

| 机制 | 作用 |
|---|---|
| 时间衰减 | 三个月没用到 → 权重减半（但**不删除**，一被命中立刻回升） |
| 使用次数 | 反复帮上忙的浮上来 |
| 相关性 | 你说"我牙疼"，优先掏和三年前那次牙科相关的 |
| 补搜 | 第一次命中太少，换最近的对话当查询再捞一遍 |

还有一层**画像**：她自己从几百条事实归纳出一段话（400 字内），
每轮必带。事实一条不少，画像是**多出来的一份**，不是替代。

```
事实 5000 条 → 她归纳 → 画像 1 段 → 每轮注入
```

### 纠正与遗忘

事实记错了**不是删掉**，而是：

- **纠正**：旧的标 `superseded` 并指向新行，**两行都留**——
  所以「她以前以为是 X」永远查得到
- **遗忘**：标 `forgotten` 并记一条事件，原文一行不动——
  「她不记得了」和「从没发生过」是两件事

### 隔离

每条事实都有 `owner`（属于谁）和 `visibility`（谁能看）：

| 级别 | 含义 |
|---|---|
| `private` | 只有归属者本人 |
| `shared` | 可以给非主人看的基础偏好（爱吃什么、爱好） |
| `public` | 世界观 / 角色设定 |

实测：

```
主人看到：  - 我｜睡眠：经常失眠到两点
            - 我｜饮食偏好：爱吃辣
陌生人看到：- 我｜饮食偏好：爱吃辣      ← 私密那条没漏
```

### 群聊里的话归谁（v0.2.1）

```
你在群里说话  → 你的池（来源标「群 X」）
                如果不算私密，也进群的池
别人在群里说  → 他的池（来源标「群 X」），同样规则
```

两份一起写、一起删。**私密的不进群池** —— 你在群里说了句私事，
它记进你的池，但不会躺在群记忆里被所有人翻到。

### 「开放信息」要过两道门（v0.2.1）

一条事实要被别人问到，得**同时**满足：

| 条件 | 说明 |
|---|---|
| 可见性 = 可共享 | 你明确点过「这条可以给外人看」 |
| 话题在白名单里 | 这条讲的确实是「爱吃什么」这类事 |

话题共 19 个，三档：

- **能外传**：食物、爱好、作息、性格、口头禅、称呼
- **绝不外传**：住址、工作、行程、身体、金钱、家人、联系人、隐私
- **灰区，一律不外传**：年龄、职业、城市、情感、近况

所以「可共享 + 住址」照样不外传。**没打话题 = 没说过的** ——
没审过的东西不该默认外流。

被追问时还有一层：问到禁区她回一句像人的话，**不点头也不否认**
（纠正等于确认），也不用「我不能透露」这种客服腔。

### 印象页

侧栏「印象」：一人一页，横向切换，主人永远第一页。
每页三块，从上到下：

| 栏 | 谁写的 | 她看不看 |
|---|---|---|
| **她的画像** | 她自己从事实归纳 | **天天在用**（每轮注入） |
| 你手写的评语 | 你 | 不看，只是存着给你自己 |
| 她对别人会说的 | 从事实实时查 | 别人问起时按这个答 |

**画像**可以点「重新归纳」。觉得哪里不对就停用 ——
停用后她不再按这段理解你，但这段话留着，随时能重新启用
（停用是留痕，不是删除：删了下次归纳又生成，你的否决等于没说过）。

「删除」开放信息是**撤回**，不是忘掉 —— 事实还在，只是不再对外提。

### 跨平台

微信、B站、抖音的账号可以挂到同一个「人」下面，记忆自动汇总。
**只由你在界面上认领**——按昵称猜会撞会重名，让模型判断更靠不住。

## 记忆与心情是怎么产生的

每轮对话**发送成功之后**，在后台做四件事：

1. **原文入库** —— 一问一答两条，`event_key` 幂等，同一条读两遍不会重复记。
   切片、分词、FTS 索引都与 `dsh-bigfish` 插件的 `MemoryStore.capture()` 一致，
   所以两边建出来的库可以互相打开。顺带把这句话里提到的人挂到锚点上
   （`anchors` / `aliases`），「老爸」「爸爸」「爸」从此是同一个人。
2. **整理成认识（事实层）** —— 有 8 条新消息 / 10 分钟的限频闸门，
   攒够了才调一次模型，把原文提炼成
   `anchor + predicate + object + confidence` 的事实。
   这部分和原文分开存，因为它是**可被纠正的**：
   同一主体同一谓词出现不同内容时，旧的标 `superseded` 并指向新的，
   **两行都留着** —— 「她以前以为是 X」以后还查得到。
   忘掉也不是删除，是一条 `forget` 事件，原文照旧。
3. **判断心情** —— 把「她说的」和「对方说的」一起喂给模型，
   输出 `{moodDelta, dims, reason, confidence}`，缩幅 1/3 后写进 `mood.json`，
   同时追加一条 timeline。心情变了会顺手记一笔**余韵**：这一轮吵了、被伤了、
   被哄了，接下来几个小时她都带着这个。
4. **决定要不要补一句** —— 话已经发出去了，隔一会儿想想"刚才那句是不是没说清"，
   是就再补一条。不补也是一种结果（输出一个 `-`），不是每次都补。

注入提示词时也是两条腿：

| 段 | 内容 | 来源 |
|---|---|---|
| `## 你记得的事` | 她**听过**的原话 | `search_index` 词法检索 |
| `## 你认定的事` | 她**知道**的结论 | `facts` 里 `status=active` 的行 |

> ⚠️ 前几件事早期**全都没有**。读路径铺得很完整，写路径一行没有，
> 结果是聊一晚上记忆里一条都没有、心情页永远是 0，而且记错了只能删。
> `tools/selftest_engine_fixes.py` 与 `tools/selftest_memory.py` 现在钉住它们。

### 记忆库结构

```
<数据根>/memory.sqlite3
  ├─ messages / chunks / search_index    原文层（权威，删了就是没听过）
  ├─ anchors / aliases / anchor_sources  谁是谁（别名归一）
  ├─ facts / fact_events                 她认定的事（派生，可纠正、可遗忘）
  └─ chunk_meta / reflection_state       派生元数据与反思水位
```

**派生层可以随时重建**：记忆页的「修索引」按钮走 `memory.rebuild_derived()`，
原文一行不动，只重排 FTS 与锚点关联。体检行会告诉你「索引缺几个片段 /
有没有孤儿」，检查失败时明确说读不到，不会显示成 0。

### 检索

查询先过分词再进 FTS5 MATCH（以前整句直接丢进去，中文没有空格，
整句被当成一个 token，几乎一条都命不中），用 `bm25()` 排序，
再做一次 MMR 去冗余，最后按 `maxChars` **填满预算**而不是硬截断。
只读打开（`mode=ro`），**不再把整个库拷到临时目录**。

## 她有自己的日子

没有对话的时候她也不在待机。这是它和「接了个模型的微信机器人」最大的区别：
**她的时间是真的在走**，而她的状态决定她怎么说话。

### 一天怎么过

```
07:0x  醒来（睡够 8 小时 20 分 ± 35 分钟）→ 排今天的日程
白天   该做什么做什么，手头的事记进 life.trace
22:5x  睡前 30 分钟 —— 复盘：今天看明白了什么
23:0x  睡前 20 分钟 —— 写日记、道别
23:2x  睡（23:20 ± 42 分钟抖动）
睡觉   不回消息；半夜收到的话压到第二天早上
```

### 作息是状态，不是钟点

她的入睡点是算出来的，不是写死的：

```
bedtime = 23:20 ± 42 分钟 + 睡眠债 × 0.15
```

熬夜会把入睡点往后推，欠的睡眠债会让她提前困。`life.day`（她的「今天」）
**只在醒来时推进** —— 所以 23:50 写的日记不会被记到第二天名下。

抖动是刻意的：一个每天 23:20:00 准点上床的角色，两天就会被看出是程序。

### 日程

每天醒来排 **2~3 件事**，其中**一件必须接着昨天**（昨天没做完的顺延）。
她手头在做什么由当前时段决定，说「在忙」的时候确实有那件事。
做完能划掉，日程页能看、能改。

### 感知：她看得见外面

| 她知道 | 来源 |
|---|---|
| 现在几点、星期几、什么时段 | 本地时钟 |
| 外面天气 | Open-Meteo，**不用注册**。30 分钟刷一次，超过 24 小时的不用 |
| 你所在的城市 | 你在生活插件里填一次（留空就不播报） |
| 今天是不是节假日 | 内置法定节假日表 |
| 聊天里提到的日期 | 从事实里抽「下周三面试」这类，到日子会提一句 |

天气这一路**只读缓存不联网**：联网失败就当她不知道，不会卡住回复，
也不会编一个温度出来。

### 主动开口

不是定时发消息，是隔一会儿算一次「现在该不该说话」：距上次聊了多久、
有没有新鲜事、心情如何、这个点吵不吵人。

- 评分过线还不够，要**掷一次骰子** —— 否则她会像闹钟一样准时
- 她主动说的话**是她说的**（走同一套灵魂和心情，不是模板）
- 你回得晚了，她不会追着问

### 被冷落会往回收

超过 8 小时没回，她会真的往回收：

| 第几次 | 表现 |
|---|---|
| 1 | 话变短，主动开口的概率打折 |
| 2 | 更短，几乎不主动 |
| 3 | 问一句「你最近很忙吗」—— 一天最多一次 |

这条只在**她在意的时候**成立：问完你没回，她就安静下来了，不会连问三天。
惩罚有 6 小时的窗口，窗口过去自动恢复；你回一句就掉一级。

### 余韵：吵架不会下一句就没事

| 发生了什么 | 留多久 |
|---|---|
| 吵起来 | 4 小时 |
| 被伤到 | 2 小时 |
| 替你担心 | 3 小时 |
| 被哄暖了 | 1 小时 |

这段时间里她说话的语气还没缓过来。你道歉或示好会**软消**，
但不是立刻没事 —— 那点别扭还要再留 30 分钟。

### 复盘和日记是两件事

睡前会做两件事，看起来像，实际完全不同：

| | 复盘 | 日记 |
|---|---|---|
| 给谁看 | **她自己**（改她底层对你的理解） | **给你看**（本地一个 .md 文件） |
| 写在哪 | `soul.json` 的 `selfNotes`，界面灵魂页能看能改 | `<数据目录>/journal/2026-11-08.md` |
| 进提示词吗 | 进（下次说话会带着） | **不进**，一个字都不进 |
| 字数 | 有上限（最多留 12 条，旧的会被顶掉） | **不限** |
| 没有素材时 | 不写（宁可空着） | 照写 —— 允许只有一句「今天没什么」 |

日记有一条硬规矩：**不许编没发生的事**。
材料里没有的场景（几点吃了什么、楼下有小孩在玩）一律不写，
宁可短。这条是踩过的坑：早期版本 536 字里有大半是编的。

手写进灵魂的条**永远不会被复盘覆盖** —— 只有她自己的笔记会被顶掉。

## 多开微信

如果你的电脑上同时登录了多个微信，大肥鱼**不会替你挑**：

- 列表里只出现**正在运行**的微信号（数据库正被进程占用）
- 选错会直接报错，不会偷偷换成别的号
- 每个号记住自己上次勾选的会话，选回来自动恢复

为什么这么严：以前它按「数据库最后修改时间」选，等于随机；
而且选错之后即使那个微信退出，磁盘上的旧数据照样会被读到 ——
你以为在跟自己聊天，实际读的是别人的号。

## 防回环

文件传输助手这类「自己对自己」的会话，回复会被读回来再触发回复。
判据是**两条独立证据，缺一不可**：

| 层 | 机制 |
|---|---|
| 1 | `allow_self` 默认 false —— 自己发的消息直接跳过 |
| 2 | `msg.is_self` 为真 **且** 内容匹配刚发出去的那条 → 才判回环 |
| 3 | 归一化剥掉 `wxid_xxx:` 和 `@昵称` 前缀 |
| 4 | 连发熔断：30 秒内自动回 6 条才停 |

> ⚠️ **对方复述她的话不算回环。** 早期版本只看文字像不像，
> 「那还是叫大肥鱼吧」被原样复述回来，被判成"我们自己发的"，
> 连拦两次还触发熔断 —— 把正常聊天硬生生掐了。
> 现在对方发来的消息**永远不做内容比对**：他复述是聊天，不是回环。

日志里会看到 `[回环]` 或 `[熔断]`。

## 清空 vs 鲸落

两件事，界面和用语都分开了：

| | 清空 | 鲸落 |
|---|---|---|
| 灵魂 | 保留 —— 她还在，只是忘了 | **删掉** |
| 心情 / 记忆 / 参数 | 删 | 删 |
| 结果 | 她还在 | **她不存在了** |

鲸落必须手输「鲸落」两个字，且强制备份。

名字来自鲸鱼死亡后沉入海底 —— 身体养活一整个生态几十年。
她的一切腐朽成别的东西，但她本人不再存在。这是告别，不是清理。

## 自检

### 装完先跑这个

```cmd
BigFish.exe --selftest      逐项实测环境，不是"应该能用"
BigFish.exe --live-send     真的发一条到文件传输助手
BigFish.exe --version       版本号
```

它会真的读文件、真的解密数据库、真的调一次模型、真的定位输入框，
每项都打印实测值。哪一项红，右侧「概览」页会说下一步怎么做。

### 源码全套

```cmd
python tools/selftest.py    23 项，逐项跑下面的单元脚本
```

单项可以直接跑：

| 脚本 | 钉住什么 |
|---|---|
| `selftest.py` | 端到端：真的读到数据，不是函数返回 True |
| `selftest_vault.py` | 灵魂规则：夹取、默认值、revision、locked、布局、鲸落 |
| `smoke_vault_live.py` | **你真实那几份文件**读写不坏（自动备份还原） |
| `selftest_write_e2e.py` | 点保存之后磁盘真的变了 |
| `selftest_memory.py` | 事实 / 纠正 / 遗忘 / 检索 / 级联 |
| `selftest_plugins.py` | 插件座位 / 开关 / 注入排序 / 配置清洗 / 预览 |
| `selftest_life.py` + `_wiring` | 她的一天怎么走、接线有没有断 |
| `selftest_proactive.py` + `_pace` | 主动开口该不该说、多久说一次 |
| `selftest_inner.py` | 表达预算 / 余韵 / 被无视，这条回路 |
| `selftest_growth.py` | 日程 / 复盘 / 关系事件 / 感知 / **日记** —— 以「不许编」为主 |
| `selftest_compose.py` | 主动说的和正常回的必须是同一个人 |
| `test_persona_parity.py` | 两侧渲染逐字节一致（同一份人格不能出两个人） |
| `test_no_leak.py` | 不碰 DSH 的会话库（AST 断言，防止再长出来） |

分层的原因是**它们证明的东西不一样**：

- `selftest_vault.py` 证明**规则**对
- `smoke_vault_live.py` 证明**你真实的数据**读写不坏
- `selftest_write_e2e.py` 证明**界面上点下去之后磁盘真的变了**
- `selftest.py` 证明**整条链路真的通了**

最后一条最容易漏：单元测试全绿、界面也正常，但就是没人写记忆 ——
那是一个"缺了一块"的问题，不是"某块坏了"，只能靠真实调用来发现。

## 已知限制

### 环境

| 项 | 说明 |
|---|---|
| **只有 Windows** | 靠 UIA 操作界面，没有别的路 |
| **微信版本敏感** | UIA 热激活的 gate 地址要精确匹配，微信更新后可能要跟着改 |
| **必须管理员 + 桌面解锁** | 见上文「三条硬限制」 |
| **会抢焦点** | 发送瞬间微信跳到最前面 |
| **微信重启后失联** | 要手动重启程序 |

### 功能

| 项 | 说明 |
|---|---|
| **语音** | 收得到、听得懂，但**发不出**语音消息 |
| **群聊 @ 未做真实验证** | 三层判据做了，但真实群里可能漏回 |
| **日记只能到目录里看** | 存在 `<数据目录>/journal/`，没有界面页（刻意的：日记是给你打开看的，不是又一块仪表盘） |
| **自动更新未端到端验证** | 逻辑写了，需要真实 Release 才能证明 |
| **记忆不回写 DSH** | 微信对话进本地库，不自动合并回 DSH 那份。要合并请手动导 |
| **多个模型同时用没做** | 一次一个接口 |

### 设计上就不做的

| 项 | 为什么 |
|---|---|
| 让模型改自己的开关 | 等于让它改自己的边界 |
| 日记进提示词 | 日记是给你看的，不是她的记忆 |
| 复盘覆盖你手写的灵魂条目 | 只有她自己写的会被顶掉 |
| 按昵称猜「谁是谁」 | 会撞、会重名。只由你在界面上认领 |
| 私密内容默认外传 | 没打话题 = 没说过的 |

设计决策的完整理由见 [`.planning/decisions.md`](.planning/decisions.md)，进度见
[`.planning/progress.md`](.planning/progress.md)。
