# 大肥鱼 × 微信

一个住在微信里的 AI。不是客服，是有人格、有作息、有自己的日子的人。

她记得你说过什么，心情会被对话改变，会主动找你，也会在你长时间不回时往回收；
每天睡前给自己排第二天的日程，写一篇只存在本机的日记。声音、表情、说法都是可拆的插件。

**当前版本 `0.11.0`** · [更新日志](CHANGELOG.md) · [文档目录](docs/)

> 本文里的名字、会话、Key、音色 ID 都是占位示例。真实配置只存在你的电脑上。
> 发布包不包含 `config.json`、`settings.json`、`plugins.json` 或任何聊天数据。

## 快速开始

```
1. 解压 BigFish-0.11.0-portable.zip 到任意目录
2. 右键 BigFish.exe → 以管理员身份运行
3. 「会话」页选微信号、勾选要听的会话
4. 「设置」页填模型接口和 Key
5. 点右上角电源启动
```

要求：

| 项 | 要求 |
|---|---|
| 系统 | Windows 10 / 11 |
| 微信 | **4.1.15.53**（其他版本未验证） |
| 权限 | 管理员 |
| 桌面 | 已解锁，微信窗口可见 |
| 模型 | 任意 OpenAI 兼容接口，或内置预设 |

语音气泡是可选功能，需要额外的虚拟声卡；声音页提供一键安装。

## 它是什么

大肥鱼不是“把模型接到微信”那么简单。它把一个人拆成几个互相影响的部分：

```
灵魂      她是谁、怎么称呼你、珍视什么
记忆      原文、事实、习惯、人物关系
心情      七个维度，会被这一轮对话改变
生活      现在几点、醒着还是睡了、手头在做什么
日程      今天打算做什么，昨天没做完的顺延
说法      怎么把一句话说出口：分条、停顿、短句
声音      这一轮要不要出声，用什么情绪念
余韵      上一轮之后还留着什么
守卫      分得清“资料”和“你此刻的要求”
```

记忆、灵魂、心情是内建器官；生活、日程、说法、声音、余韵、守卫、主动、日记、表情包都是插件，能单独开关。

## 主要能力

| 能力 | 说明 |
|---|---|
| **回消息** | 短句、分条、有节奏；话多话少取决于她的状态 |
| **记得** | 原文、事实、纠正、遗忘、人物锚点；记忆有隔离，不把私密内容带给别人 |
| **有心情** | 七个维度；吵架不会下一句就没事 |
| **有自己的日子** | 作息、日程、天气、手头的事；不是等你说话才存在 |
| **会主动** | 久没聊、正好有空、有点想说话时先开口；不是定时闹钟 |
| **会往回收** | 长时间不回，话变短、主动变少，最后问一句“你最近很忙吗” |
| **写日记** | 每天睡前一篇本地 Markdown，只给你看，不进提示词 |
| **发表情** | 说完话合适时跟一张，从本地收藏里挑 |
| **发语音** | 云端声音模型；可发音频文件，也可发微信语音气泡（实验链路） |
| **可改** | 灵魂、心情、记忆页面能直接写；每块插件都有开关和参数 |

## 安装

### 便携版

下载 Release 里的 `BigFish-<version>-portable.zip`，解压到任意目录，运行 `BigFish.exe`。

- 首次运行会在程序目录下创建 `data/`；
- 升级时只替换程序文件，不要覆盖 `data/` 和 `config.json`；
- 整个目录可以搬到别的盘，数据跟着走。

### 源码运行

```cmd
python -m venv .venv
.venv\Scripts\python.exe -m pip install --no-cache-dir setuptools wheel
.venv\Scripts\python.exe -m pip install --no-cache-dir --no-build-isolation --no-deps -e vendor/wechatauto-replica
.venv\Scripts\python.exe -m pip install --no-cache-dir ^
  uiautomation pywin32 pyperclip Pillow psutil colorama ^
  cryptography zstandard PySide6-Essentials PySide6-Addons PySide6-WebEngine numpy capstone
```

然后：

```cmd
python -m bigfish.desktop
```

源码运行同样需要管理员权限。

## 第一次配置

大部分配置在界面里完成，不需要手改文件。

1. **选微信号**：会话页只列出当前正在运行的微信账号。多开时程序不会替你猜。
2. **勾选会话**：私聊写昵称，群聊写群名；保存后监听立即生效。
3. **接模型**：设置页选择渠道，填 `base_url`、模型名、Key。内置预设覆盖常见 OpenAI 兼容服务，也可以选 `custom` 填任意网关。
4. **启动**：点右上角电源。日志会逐项显示灵魂、数据库、UIA、监听会话是否就绪。
5. **可选：声音**：插件页启用「声音」，侧栏出现声音页，再填语音模型 Key、音色 ID 和出声策略。

`config.json` 只保存本机配置；`config.example.json` 是公开示例，里面没有真实 Key。

## 声音

声音是 0.11.0 的主要新增能力。

### 接入

- 引擎：Breeze TTS 2 Multilingual（也兼容单语模型）；
- 接口地址、Key、音色 ID 在「声音」页填写；
- 语速固定 `1.00`，情绪和场景由本地导演层生成；
- 输出 24kHz 单声道 WAV，先落盘再发送。

### 什么时候出声

声音页可以配置：

- 关闭 / 只在要求时 / 自动判断 / 按概率 / 每条都发 / 预演；
- 概率、冷却、每日上限、连续语音上限；
- 最长字数、场景白名单、链接/代码/表格/清单过滤；
- 群聊是否出声、是否只对主人出声；
- 失败时是否补文字。

**命中语音后只发语音，不会再发同内容文字。** 旧配置里的“先文字再语音”会自动迁移为只发语音。

语音长度按合成后的实际时长判断：**超过 50 秒自动改发文字**。微信上限是 60 秒，留 10 秒容错。

### 音频文件与语音气泡

| 形式 | 说明 |
|---|---|
| 音频文件 | 把 `.wav` 当普通文件发送；不需要虚拟声卡，最稳 |
| 微信语音气泡 | 模拟“按住录音”发送；需要 VB-CABLE 虚拟声卡，实验性 |

语音气泡的路线：

```
本程序 → CABLE Input（播放）→ VB-CABLE → CABLE Output（微信麦克风）
```

声音页顶部提供 **一键安装 VB-CABLE**：

- 内置官方 Pack45，31 个文件逐一 SHA256 校验；
- 点按钮后弹 Windows UAC，安装程序静默运行；
- 装完可能需要重启电脑/微信，再点“刷新声卡”；
- 微信麦克风要选 `CABLE Output`；程序播放端选 `CABLE Input`；
- 微信“发语音”快捷键要和声音页填的完全一致。

气泡失败分两级：

- **还没按录音键**：改发同一份音频文件，不重新合成、不浪费已花的额度；
- **已经按过录音键**：结果未知，不补发文件或文字，避免对方收到两遍。

气泡发送前会主动把微信窗口置前；只有系统前台锁仍然挡住时才回退。

## 记忆与心情

记忆分四层：

```
原文层  messages / chunks / search_index   她听过什么
事实层  facts                              她认定什么，可纠正、可遗忘
习惯层  habits                             说过三次以上的原话样本
身份层  owners / persons                   谁是谁
```

每轮发送成功后，后台会：

1. 把一问一答写进原文库；
2. 攒够消息后提炼事实；
3. 判断心情变化，写入心情和余韵；
4. 决定要不要补一句。

事实记错了不是删除，而是标 `superseded` 并指向新行；遗忘是标 `forgotten`。两行都保留，所以“她以前以为是 X”仍然查得到。

记忆有归属和可见性：`private` / `shared` / `public`。私密内容不会因为开了群聊就进群池。

## 她自己的日子

没有对话时，她的时间也在走：

- 按睡眠债算出作息，不是固定钟点；
- 每天醒来排 2–3 件事，其中一件接着昨天；
- 天气来自 Open-Meteo，失败就当不知道，不编温度；
- 主动开口要过分数和概率两道门，不是定时发消息；
- 长时间不回，会触发“往回收”；
- 吵架、被伤、担心、被哄暖会留下不同时长的余韵；
- 睡前复盘写进灵魂，日记写进本地 `journal/`，两者不混。

## 数据与隐私

默认数据目录：

```
<安装目录>/data/
  ├─ soul.json          她是谁
  ├─ mood.json          此刻怎样
  ├─ life.json          作息、日程、手头的事
  ├─ afterglow.json     上一轮之后还留着什么
  ├─ proactive.json     主动开口的账
  ├─ memory.sqlite3     原文、事实、习惯、人物关系
  ├─ plugins.json       插件开关和参数
  ├─ journal/           日记
  ├─ stickers/          表情收藏
  ├─ history/           每个会话最近一段对话
  ├─ prompts/           每轮提示词快照
  └─ _outbox/           待发队列
```

`settings.json` 记录你改过的数据目录，永远在安装目录，不跟着 `data/` 搬。

### 不会上传的东西

- 微信聊天记录、数据库密钥（`wechatauto_db/` 整个目录）；
- `config.json` 里的模型 Key、语音 Key；
- 灵魂、心情、记忆、日记、表情收藏；
- `settings.json`、`plugins.json`；
- `data-backup/`、`dist/`、`release/`、`.secrets/`。

发布脚本生成的便携包会显式跳过 `config.json`、`settings.json`、`plugins.json`、`data/` 和 `wechatauto_db/`。仓库的 `.gitignore` 也把这些路径挡在提交之外。

> 换机器或备份：直接拷整个 `data/`；不要只拷 `memory.sqlite3`，灵魂和心情不在里面。

## 三条硬限制

### 管理员权限

UIA 热激活需要往微信进程写入一个运行时无障碍标志字节。普通权限会 `ACCESS_DENIED`；管理员权限才能写入。写的是 1 个字节，不注入代码、不挂 DLL、不改微信文件，微信重启即恢复。

### 桌面必须解锁

UIA 操作的是真实界面。锁屏后没有控件树，发送会失败。

### 会抢焦点

发送瞬间微信窗口会到前台。语音气泡还需要按住录音快捷键，录音期间微信会被占用；其他会话的发送会排队。

## 群聊与防回环

群聊默认只在被 @ 或叫名字时回复。判据包括微信 @ 占位符、群成员表、昵称精确匹配；也可以在作用域里给某个群开“无条件回”。

防回环分四层：

1. `allow_self` 默认关闭，自己发的消息跳过；
2. 身份判定确认“这条是不是自己”；
3. 账本比对刚发出去的正文；
4. 30 秒内自动连发 6 条触发熔断。

`allow_self` 按现有设计只对 **文件传输助手** 生效，用来做自测通道。其他会话里自己发的消息不会触发回复，但会在日志里写明“跳过”，不再静默消失。

## 并发与投递

```
watcher → 防抖批处理 → 生成队列（2 个 worker）
                         └→ 每会话锁：同会话串行、跨会话并行
                              └→ 投递队列（1 个 worker，唯一碰 UIA）
```

生成可以并行，投递必须串行：一个微信窗口、一个输入框、一个剪贴板。语音气泡的录音阶段会独占微信，其他发送等待。

## 已知限制

| 项 | 说明 |
|---|---|
| 只有 Windows | 依赖 UIA，没有跨平台发送路径 |
| 微信版本敏感 | 热激活地址要匹配；升级微信后可能需要适配 |
| 必须管理员 + 桌面解锁 | 见“三条硬限制” |
| 会抢焦点 | 发送瞬间窗口置前 |
| 微信重启后可能失联 | 需要重启程序或重新唤醒 |
| 语音气泡是实验链路 | 依赖微信版本、UIA 控件名、快捷键、VB-CABLE |
| 群聊 @ 未做大规模真实验证 | 判据已做，真实群可能漏回 |
| 日记没有独立界面 | 直接打开 `<数据目录>/journal/` |
| 自动更新未端到端验证 | 需要真实 Release 证明 |
| 记忆不回写 DSH | 微信对话留在本地库，要合并请手动导 |
| 多模型同时用未做 | 一次一个接口 |

设计上刻意不做：让模型改自己的开关、日记进提示词、复盘覆盖手写灵魂条目、按昵称猜“谁是谁”、私密内容默认外传。
